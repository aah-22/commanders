# commanders

Washington Commanders front-office analytics — nflverse → Postgres → FastAPI → Angular, with MLflow-tracked models
that grade acquisitions and rank targets, and a DevSecOps pipeline (ruff, bandit, pip-audit, ESLint, npm audit,
Trivy, CycloneDX SBOM, CodeQL, gitleaks, SonarCloud). Live at https://commanders.caabi.dev.

Start with [`docs/commanders-build-guide.md`](docs/commanders-build-guide.md) (architecture, phases, definitions of
done) and [`docs/DEPLOY.md`](docs/DEPLOY.md). No betting or odds content.
